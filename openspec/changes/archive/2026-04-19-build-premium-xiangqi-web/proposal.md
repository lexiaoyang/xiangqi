## Why

当前项目缺少一个可直接对标优秀在线棋类产品的中国象棋 Web 体验，无法覆盖从新手到高阶玩家的完整对弈需求。现在推进该变更，可以一次性建立高品质视觉、分层 AI 难度、限时对局与强推荐走法能力，为后续增长和竞技玩法打下基础。

## What Changes

- 新增完整的中国象棋 Web 应用壳与核心对局页面，支持响应式布局、沉浸式棋盘与精美动效主题。
- 新增三档 AI 难度：简单、困难、地狱；难度通过不同搜索深度、评估函数与开局库策略区分强度。
- 新增每步最大等待 1 分钟的回合时钟与超时处理机制（倒计时、超时判负/托管策略可配置）。
- 新增推荐走法系统（可一键采用），目标是推荐链路在地狱模式对战中达到稳定优势，逼近人类顶尖棋手级决策质量。
- 新增对局体验增强：复盘、悔棋规则、局势评估条、棋谱导出、关键事件提示、无障碍与移动端适配。
- 新增性能与质量保障：AI 计算异步化、缓存与限流策略、可观测性埋点、自动化测试与基准对局评测。

## Capabilities

### New Capabilities
- `xiangqi-core-gameplay`: 中国象棋规则引擎、合法走子校验、胜负判定与棋局状态管理。
- `xiangqi-premium-ui`: 高品质 Web 棋盘界面、主题系统、动画反馈、响应式与可访问性支持。
- `xiangqi-ai-difficulty-engine`: 简单/困难/地狱三档 AI 对弈引擎与策略参数体系。
- `xiangqi-turn-timer-and-assist`: 1 分钟步时控制、超时处理、推荐走法展示与一键采用。
- `xiangqi-analysis-and-replay`: 复盘、局势评估、棋谱导入导出与关键节点分析。

### Modified Capabilities
- 无

## Impact

- 代码影响：前端应用框架、棋盘渲染层、规则引擎、AI 服务层、状态管理、数据存储与遥测模块。
- API 影响：新增对局会话、AI 求解、推荐走法、棋谱分析等接口；需要定义版本化契约。
- 依赖影响：可能引入 UI 动效库、Web Worker/计算引擎、棋力评测数据集与监控 SDK。
- 系统影响：需要建立 AI 推理性能预算（移动端/低配机型）与对局质量评测基线（特别是地狱模式与推荐链路）。
