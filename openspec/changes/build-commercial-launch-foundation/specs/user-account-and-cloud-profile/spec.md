## ADDED Requirements

### Requirement: 用户支持游客登录与正式账号绑定
系统 MUST 支持游客身份快速进入，并支持后续绑定正式账号，绑定后用户资产与历史对局数据 SHALL 保持一致。

#### Scenario: 游客绑定正式账号后数据保持
- **WHEN** 游客用户完成账号绑定流程
- **THEN** 系统 MUST 将游客期间的对局、配置与资产迁移到正式账号且不丢失

### Requirement: 对局与配置数据云同步
系统 SHALL 提供云端数据同步能力，使用户在不同设备登录后可恢复最近对局记录、偏好设置与复盘历史。

#### Scenario: 跨设备恢复数据
- **WHEN** 用户在新设备登录同一账号
- **THEN** 系统 MUST 拉取并恢复该账号的最新云端数据快照
