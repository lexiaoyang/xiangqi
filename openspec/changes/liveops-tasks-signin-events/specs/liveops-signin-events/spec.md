## ADDED Requirements

### Requirement: 任务与签到配置下发
系统 MUST 支持按活动版本下发任务与签到配置，客户端仅渲染当前生效版本。

#### Scenario: 活动版本生效切换
- **WHEN** 新活动版本达到生效时间且校验通过
- **THEN** 客户端拉取到新版本配置并替换旧版本展示

### Requirement: 进度累计与领奖幂等
系统 SHALL 对任务进度累计和奖励领取执行幂等控制，防止重复领奖。

#### Scenario: 重复领奖请求被拒绝
- **WHEN** 用户对同一任务奖励连续提交两次领取请求
- **THEN** 系统仅首次发奖成功，后续请求返回已领取状态
