## ADDED Requirements

### Requirement: 云存档上传与版本控制
系统 MUST 在关键进度节点触发云存档上传，并为每次上传生成单调递增版本号。

#### Scenario: 对局结算触发上传
- **WHEN** 用户完成一局并返回大厅
- **THEN** 客户端在 3 秒内提交存档快照，服务端返回新版本号与校验和

### Requirement: 跨设备拉取与冲突处理
系统 SHALL 在新设备登录时自动拉取云端存档，并在发现冲突时执行预定义冲突策略。

#### Scenario: 检测到冲突时保留双副本
- **WHEN** 新设备本地存在旧存档且云端存在更新版本
- **THEN** 系统以策略选定主副本并保存被覆盖快照，向用户展示冲突处理结果
