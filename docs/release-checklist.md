# 发布清单与回滚预案

## 发布前门槛

- 规则单元测试全部通过（含将军、终局、序列化）。
- 三难度 AI 回归通过，地狱模式达到设定对抗阈值。
- 推荐链路基准胜率达到压制地狱模式标准。
- 计时器和超时裁定在端到端流程可复现。
- 复盘与棋谱导入导出一致性通过。
- 低配设备降级策略验证通过。

## 发布流程

1. 执行 `npm test` 与 `npm run build`。
2. 记录版本号、配置版本和棋力评测结果。
3. 灰度上线并观察错误率、平均响应时间、超时中断比例。
4. 全量发布。

## 回滚策略

- 任一核心指标异常（规则错误、AI 长时无响应、推荐胜率跌破阈值）立即回滚到上个稳定版本。
- 回滚后关闭高风险入口：`地狱模式` 与 `推荐走法`。
- 保留日志与复盘样例，修复后重新执行全量回归再发布。
