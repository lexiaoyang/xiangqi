# 游客绑定灰度与回滚清单

## 灰度发布

- [ ] 仅 5% 流量开启绑定入口。
- [ ] 观察 30 分钟错误率、冲突率、重试率。
- [ ] 指标正常后扩容到 20%/50%/100%。

## 告警阈值

- [ ] `RATE_LIMITED` 占比 > 8% 触发风控复核。
- [ ] `TRANSIENT_FAILURE` 占比 > 5% 触发服务降级。
- [ ] 绑定成功率低于 92% 触发回滚评估。

## 回滚预案

- [ ] 关闭绑定入口开关，保留游客游玩能力。
- [ ] 保留会话创建与续期，不影响已登录用户。
- [ ] 回滚后导出失败样本用于复盘。

## 运营验收

- [ ] 绑定成功文案与失败文案经过运营确认。
- [ ] 客服 FAQ 包含冲突与重试说明。
- [ ] 数据看板可查看绑定漏斗（进入 -> 提交 -> 成功）。
