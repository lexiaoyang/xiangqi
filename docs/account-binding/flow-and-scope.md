# 游客绑定能力范围与流程

## 业务范围

- 角色：游客用户、已注册用户、运营与客服。
- 范围：游客身份创建、会话续期、绑定正式凭据、冲突确认、回滚恢复。
- 非范围：多账号切换器、跨区服资产迁移。

## 关键流程（文本流程图）

1. 首次启动 -> 检测本地会话为空 -> 创建 `guest_id` + token -> 进入游客态。
2. 进入设置页 -> 提交绑定信息（手机号/微信 + 验证码）-> 服务校验。
3. 若无冲突 -> 写入绑定信息 -> 返回已绑定态会话。
4. 若有冲突 -> 返回冲突码 -> 用户勾选“允许合并”后重试。
5. 任意中断/失败 -> 使用回滚快照恢复到绑定前游客会话。

## 参与模块

- 客户端：设置页绑定表单、状态展示、重试与回滚触发。
- 账号服务：会话生成、续期、绑定校验、冲突检测。
- 可观测：绑定事件埋点、异常日志、高频尝试告警。
